# 뚜버기 Android 네이티브 시제품

기존 웹·Expo 프로젝트를 보존하고 별도로 만든 **Kotlin + Jetpack Compose** 시제품입니다.
홈·조건 선택·실제 추천·카카오 지도에 더해, **로그인/가입/소셜 로그인 연결·내 여행·저장/삭제·코스 상세/편집·AI 설명·날씨**를 복원했습니다.
여러 날/숙소 입력도 연결했지만 일부 다일 조건에서 적합 코스를 찾지 못합니다. 푸시 알림·정식 스토어 출시는 미완료입니다.
공개 문의: waboranggae.help@gmail.com. 운영 주체: 뚜버기 Team (administrator: Taeyoung Ko).
개인정보 동의는 최초 이용/새 동의가 필요한 경우에만 확인하고, 동의한 계정의 재로그인에는 반복하지 않습니다.

## 바로 확인할 파일

- 이번 검증 결과와 미완료 항목: `VALIDATION.md`
- 원래 웹 디자인과 네이티브 대응 범위: `DESIGN_PARITY.md`
- 설치용 APK: `app/build/outputs/apk/debug/app-debug.apk`
- 실제 API 검사: 상위 프로젝트의 `.runtime/native-pilot/api-smoke.json`
- APK 보안 검사: 상위 프로젝트의 `.runtime/native-pilot/apk-audit.json`
- 단위 테스트 보고서: `app/build/reports/tests/testDebugUnitTest/index.html`
- Android 정적 검사: `app/build/reports/lint-results-debug.html`

APK는 S20+용 **ARM64 디버그 빌드**입니다. Expo Go가 필요 없습니다. 현재 휴대폰에 설치된 기존 앱을 덮어쓰지 않는 별도 패키지를 사용합니다.
개발 서버 접속용 키가 들어 있으므로 팀 내부 테스트만 하고, 공개 업로드하거나 스토어에 제출하지 마세요.

## 카카오 설정: 사용자가 직접 확인할 부분

네이티브 키는 상위 프로젝트 **`.env`**에 넣으면 됩니다.

```dotenv
KAKAO_NATIVE_APP_KEY=발급받은_네이티브_앱_키
```

`tools/build.ps1`이 `.env`의 키를 `local.properties`로 자동 반영합니다. 키를 채팅에 보낼 필요가 없습니다.
`local.properties`는 Git에서 제외됩니다. `.env`와 `local.properties` 모두 공개하면 안 됩니다.

카카오디벨로퍼스의 해당 앱에서 **앱 → 플랫폼 키 → 네이티브 앱 키**를 열고, 사용 중인 키의 Android 앱 정보에 아래 값을 등록해 주세요.

| 항목 | 시제품 값 |
| --- | --- |
| Android 패키지명 | `kr.co.waboranggae.nativepilot` |
| 현재 PC 디버그 서명 키 해시 | `+lJ1teWYUV40Nxs3SeJj74PO5kU=` |

키 해시는 **비밀번호가 아닌 서명 인증서의 공개 식별값**입니다.
다른 개발자 PC나 출시 서명으로 빌드하면 해당 서명의 키 해시를 별도로 등록해야 합니다.
이미 키를 넣었어도 패키지/키 해시가 등록되지 않으면 지도는 인증 오류를 표시할 수 있습니다.
관리자 설정은 이번 작업에서 대신 변경하지 않았습니다.

공식 안내: https://apis.map.kakao.com/android_v2/docs/getting-started/quickstart/

## 이 PC에서 빌드·설치

상위 `waboranggae` 폴더에서 PowerShell을 열고 실행합니다.

```powershell
# APK 생성 + 단위 테스트 + Android 정적 검사 (휴대폰 불필요)
powershell -NoProfile -ExecutionPolicy Bypass -File .\android-native\tools\build.ps1 -Test

# USB 디버깅을 승인한 휴대폰 1대에 시제품 설치 및 실행
powershell -NoProfile -ExecutionPolicy Bypass -File .\android-native\tools\build.ps1 -Install

# 잠금을 직접 해제한 휴대폰에서 실제 API UI 흐름 자동 검사
powershell -NoProfile -ExecutionPolicy Bypass -File .\android-native\tools\device-test.ps1
```

`ExecutionPolicy Bypass`는 해당 명령의 프로세스에만 적용하며 PC의 영구 실행 정책은 바꾸지 않습니다.
설치 과정에서 휴대폰에 보안 확인 창이 나타나면 사용자가 직접 승인해야 합니다. 스크립트는 잠금 해제나 보안 경고 우회를 하지 않습니다.
USB는 개발 도구 설치·APK 빌드 중에는 빼도 됩니다. APK 설치·실기 테스트 중에는 연결을 유지해 주세요.

설치 후 앱 목록에서 **뚜버기**를 실행합니다. 연결을 빼도 설치된 앱은 실행됩니다.
다만 실제 추천은 현재 PC의 개발 API·DB가 켜져 있고 공개 HTTPS 주소로 접근할 수 있어야 합니다. 이 앱은 서버를 휴대폰 안에 넣는 방식이 아닙니다.
임시 개발 서버 주소가 바뀌면 `team:start` 후 다시 빌드·설치해 주세요.

## S20+에서 볼 순서

1. 걷는 사람 아이콘 → 전남 지도·발자국 → 로그인 화면을 확인합니다. 새 계정 생성/소셜 로그인은 개인정보 동의가 필요하며, **게스트로 이용하기**로도 홈에 들어갈 수 있습니다.
2. 홈의 **전남 여행 소식**에서 실제 관광사진·축제 카드를 누르면 상세 정보가 나옵니다.
3. **여행 코스 만들기** → 출발지 검색에 `순천 종합버스터미널`을 입력하고 검색 결과를 선택합니다.
4. 출발 → 지역·시간 → 걷기·동행 → 목적·식사 → 교통의 **5단계**를 진행합니다. 6시간, 자연·맛집·카페, 시내버스 조건으로 추천해 보세요.
5. 결과의 출발지·소요 시간·사진·추천 이유를 확인합니다. 예시 코스는 실제 결과처럼 표시하지 않습니다.
6. 코스 카드 → 상세(시간표·점수·AI 설명·현재 날씨) → **이 코스로 동선 확인** → **코스 2**를 누릅니다. 제목·출발지·장소가 일치해야 합니다.
7. 지도 핀 또는 아래 장소 칩을 누르면 해당 관광지의 사진·주소·설명을 표시합니다.
8. 로그인했다면 상세에서 코스/조건을 직접 저장하고, 내 여행에서 조회·삭제·로그아웃을 확인합니다. 실제 계정 삭제 버튼은 복구가 불가능하니 테스트 계정에서만 확인하세요.
9. 카카오·구글 버튼 → 인증 창 열기 → 브라우저에서 직접 인증 → 앱으로 돌아옵니다. 인증 암호/보안 확인은 사용자가 직접 처리해야 합니다.
10. 뒤로가기, 추천 중 취소, 네트워크 끊김 후 재시도, 앱 종료 후 재실행을 확인합니다.

지도의 관광지 좌표와 추천 이동 시간은 서로 다른 데이터입니다. 서버가 `estimated`로 반환한 이동 시간은 추정값으로 표시하고, 두 좌표를 이은 직선을 실제 길처럼 그리지 않습니다.
네이티브 지도는 방문 위치·핀을 보여주며 실시간 버스 도착이나 턴바이턴 내비게이션을 제공하는 시제품은 아닙니다.

## 보존·보안·구조

- 기존 웹·Expo 앱과 DB는 보존했습니다. 서버 동의·사진 프록시 보안 및 다일 식사 검증을 수정했고, 팀 DB에는 동의 버전/시각 컬럼만 추가했습니다. 다른 DB에서 실행할 때는 새 마이그레이션을 먼저 적용해야 합니다.
- `MainActivity` → `TravelViewModel` → `TravelRepository` → 기존 HTTPS API 구조입니다.
- 출발지는 실제 장소 검색 결과의 위도·경도를 전송합니다. 역/터미널 문자열만으로 임의 대체하지 않습니다.
- 추천 결과는 ID로 선택해 지도에 전달하므로 첫 번째 코스에 고정하지 않습니다.
- TourAPI·DB·JWT·OAuth 비밀키는 앱에 넣지 않습니다. 외부 이미지에는 개발 서버 인증 헤더를 전송하지 않습니다.
- 앱에 추가한 사용자 권한은 인터넷뿐입니다. 현재 위치·사진첩·연락처 권한은 요청하지 않습니다.
- 릴리스 빌드는 의도적으로 차단했습니다. 고정 서버·출시용 서명·계정/개인정보 정책·Play Console 검증 전 공개 배포하면 안 됩니다.
- 초기 SDK 준비는 `tools/bootstrap.ps1 -AcceptAndroidSdkLicense`이며, 이 옵션은 사용자가 라이선스 동의를 승인했을 때만 사용합니다.
- 웹의 흑백 버튼·카드·4개 하단 메뉴·Pretendard 글꼴을 기준으로 Compose 화면을 구현했습니다. 웹 전체 기능을 자동 변환한 것은 아닙니다.
- 전남 지도·발자국 SVG는 `tools/sync-web-art.mjs`가 웹 `Splash` 원본에서 추출합니다. 빌드 시 실행되며 새로운 그림을 생성하지 않습니다.
- 걷는 사람은 웹과 같은 `🚶` 문자입니다. 설치 아이콘도 S20+에서 같은 글리프를 렌더링한 자산이며, 기존 녹색 W2 로고나 주황색 목적지 핀은 사용하지 않습니다.
- Pretendard v1.3.9 원본 글꼴을 번들로 포함했습니다. OFL 라이선스는 `PRETENDARD-LICENSE.txt` 및 APK assets에 함께 들어 있습니다.

## 판단 기준

PC에서의 빌드/테스트 통과와 S20+ 실기 검증은 구분합니다. **홈 표시·지도 인증·실제 기기 사용성까지 확인한 뒤** 네이티브 전면 전환 여부를 결정합니다.
실기 테스트에서 카카오 지도가 실제로 보이지 않으면 단순히 지도 뷰가 생성됐다는 이유로 지도 테스트를 통과 처리하지 않습니다.
