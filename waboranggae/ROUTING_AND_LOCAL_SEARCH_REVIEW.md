# 추천 전 경로 검증·단말기 내 검색 정렬 검토

검증일: 2026-09-16 KST. 대상: Supabase 비공개 API 및 Galaxy S20+ 네이티브 앱.
기존 웹·Expo·DB·휴대폰 앱 데이터를 유지했습니다. GitHub 업로드, 스토어 제출, 유료 서비스 활성화는 하지 않았습니다.

## 반영한 구조

1. 관광정보와 조건으로 후보를 만들고 추정 일정으로 1차 선별합니다.
2. 상위 최대 3개에 카카오 도보·대중교통 경로를 조회합니다.
3. 실제 조회 이동 시간에 체류 시간을 조정하고 식사 순서·도착 시각·총 시간·점수·조건을 재검증합니다.
4. 조건 통과 및 실제 경로 확인 결과를 우선하여 목록에 표시합니다. 공급자 실패 구간은 추정/혼합으로 구분합니다.
5. 5분 이내 확인한 코스를 열 때 불필요하게 즉시 재조회하지 않습니다. 수동 새로고침과 장소 편집은 다시 검증합니다.

도시 간 **출발지 → 첫 장소** 이동도 요청 여행 시간에 포함됩니다. 귀가 이동은 포함하지 않습니다. 체류 시간은 여전히 계획값이며, 총 시간이 8시간으로 표시되어도 전 구간을 실측했다는 뜻은 아닙니다. 카카오 경로는 조회 시점 정보여서 미래 여행일 배차나 실제 소요 시간을 보장하지 않습니다.

중간 거리(0.6~2km)는 실제 도보/대중교통을 비교하며 걷기 제한을 함께 적용합니다. 코스 간 같은 구간은 공유하고, 한 번의 경로 검증 작업에서 새 조회를 최대 24건으로 제한합니다. 제한·장애 발생 시 실제 경로로 위장하지 않습니다. 전체 후보 생성은 여전히 추정 기반이므로 전 후보를 실경로로 전수 최적화한 것은 아닙니다.

## 출발지 자동완성 및 개인위치정보

- 일반 자동완성은 사용자가 입력한 검색어만 서버와 카카오 검색 API로 전달합니다. 서버는 위치 좌표가 포함된 검색 쿼리를 거부합니다.
- ‘내 주변 가까운 순’ 버튼은 설명 후 대략적 위치 권한을 선택적으로 요청합니다. 거부·취소·위치 조회 실패 시 일반 검색은 계속됩니다.
- 실제 현재 위치는 `DeviceOnlyLocation`이라는 UI 전용 객체로만 유지합니다. 저장 상태·파일·DB·로그·분석 도구·지도 SDK·서버 요청에 연결하지 않습니다.
- 화면을 떠나거나 앱이 백그라운드로 가면 조회를 취소하고 좌표를 해제합니다.
- 서버가 돌려준 검색 후보만 휴대폰에서 직선거리로 정렬합니다. 전국의 모든 장소 중 가장 가까운 곳을 보장하거나 현재 위치로 카카오 검색 범위를 좁히지 않습니다. 정확히 일치하는 주소는 먼저 유지합니다.
- **사용자가 선택한 출발 장소의 좌표**는 추천 경로 계산에 사용됩니다. 이는 단말기 현재 위치를 자동 전송하는 동작과 별개입니다. 사용자가 직접 입력하는 주소·장소 검색까지 오프라인이라는 뜻은 아닙니다.

기술 확인: Android의 [위치 권한](https://developer.android.com/develop/sensors-and-location/location/permissions), [단발 위치 조회/취소](https://developer.android.com/reference/androidx/core/location/LocationManagerCompat), 카카오 [로컬 검색](https://developers.kakao.com/docs/ko/local/dev-guide). 현재 위치를 검색 중심으로 전송하는 기능은 사용하지 않습니다.

## 사진 출처 위치

추천 목록 및 코스 상세의 대표 사진에서는 출처 오버레이를 제거했습니다. 사진 바로 아래에도 따로 붙이지 않습니다. 상세 화면의 **‘이 코스로 동선 확인’ 버튼 아래 기존 안내문**에 관광정보·사진 제공처를 함께 표기합니다. 홈·지도 정보창의 기존 출처 표시는 별도로 유지합니다. 이 UI 변경이 사진별 이용 허락을 새로 확보하거나 저작권 검토를 완료한 것은 아닙니다.

- 실제 테스트 중 앱 자체 보호 한도 100회에 도달했습니다. 사용자가 무료 적용 및 유료 미사용 상태를 확인하고 증액을 허용했습니다.
- Git 제외 파일 `.env.edge.local`과 해당 Supabase 프로젝트 설정의 `KAKAO_DAILY_REQUEST_LIMIT`만 **300**으로 변경했습니다.
- 사용량은 초기화하지 않았습니다. 한도 변경 직후 100회, 최종 실기 검사 후 읽기 전용 조회 **134/300회**를 확인했습니다. 이 값은 해당 시점의 기록입니다.
- 카카오 요금제·유료 API 활성화·공급자 공식 쿼터는 변경하지 않았습니다. 보호 한도 확대는 추가 비용이 영구적으로 없음을 보장하는 계약이 아닙니다. [공식 쿼터 안내](https://developers.kakao.com/docs/ko/getting-started/quota)
