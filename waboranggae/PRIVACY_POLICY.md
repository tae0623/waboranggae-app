# 뚜버기 개인정보 안내 — 개발 테스트용

버전: 2026-09-15-consent-v2. 문의: waboranggae.help@gmail.com.
운영 주체: **뚜버기 Team (administrator: Taeyoung Ko)** — 사용자 확정 표기.
이 문서는 법률 검토 완료 또는 스토어 출시 가능 확인서가 아닙니다.

## 실제 제공되는 안내

서버의 `/legal/privacy`가 앱·웹의 현재 안내 원본입니다 (`server/src/legalContent.ts`).
네이티브 로그인 및 내 여행에서 개인정보·출처 안내를 열 수 있습니다.
`/legal/delete-account`는 앱 설치 없이 이메일 본인 확인 후 삭제하는 페이지이며,
소셜 계정은 웹 로그인 후 내 여행의 삭제 기능을 안내합니다.
현재 임시 개발 주소·팀 인증을 사용하는 상태이므로 영구 공개 URL 및 실제 소셜 삭제 흐름을 출시 전에 확인해야 합니다.

## 처리 항목·목적·기간

| 구분 | 항목 | 목적·보관 |
| --- | --- | --- |
| 이메일 계정 | 이메일, 표시 이름, 비밀번호 해시 | 계정 관리, 탈퇴 시까지 |
| 소셜 계정 | 공급자 식별자, 표시 이름 (앱 내부 식별용 대체 이메일 포함) | 계정 관리, 탈퇴 시까지. 제공자 비밀번호는 받지 않음 |
| 계정 이용 동의 | 안내 버전, 동의 시각 | 현재 동의 기록, 탈퇴 시까지. 기존 사용자에게 소급 동의 처리하지 않음 |
| 신규 소셜 인증 임시 정보 | 공급자 식별자·표시 이름 | 인증 확인, 동의 전 사용자 계정은 생성하지 않음. 임시 DB에 암호화 저장, 5분 만료·매분 정리. 서버 중단 시 재개 후 삭제 |
| 선택 저장 | 코스 원본, 출발지·좌표, 일시, 취향·동행 조건 | 사용자가 직접 저장, 항목 삭제 또는 탈퇴 시까지 |
| 추천 처리 | 입력 조건·장소·좌표 | 관광·경로·날씨 추천. 추천 캐시는 15분 유효, 1분 정리, 최대 200건 |
| 로그인 유지 | 액세스/갱신 토큰 | 액세스 토큰은 메모리, 갱신 토큰은 Android Keystore 암호화·백업 제외 저장. 로그아웃 시 기기 저장 삭제 |

이메일 가입은 가입 전, 기존 동의 없는 이메일/소셜 계정은 인증 후 이용 전, 신규 소셜 계정은 DB 등록 전에 안내를 읽고 직접 체크합니다.
같은 동의 버전과 시각이 계정에 있으면 재로그인·자동 로그인 시 다시 묻지 않고 원래 동의 시각을 유지합니다.
일반 앱 업데이트마다 동의를 요구하지 않습니다. 새로운 동의가 필요한 실질적인 처리 변경일 때만 안내 버전을 바꿉니다.
미동의/이전 버전 계정의 새 저장·프로필 수정은 서버에서도 차단하지만 기존 정보 조회·삭제와 게스트 이용은 허용합니다.
계정 여행 이력은 자동 기록하지 않습니다. 웹은 저장 전 확인, 네이티브는 명시적 저장 버튼과 확인창을 사용합니다.
토큰 자체에 이메일이 들어가는 기존 JWT 설계와 서버 갱신 정책은 추가 최소화 검토 대상입니다.

## 외부 처리 및 출시 전 확정

관광·사진은 한국관광공사, 지도·검색은 카카오, 날씨는 기상청, 교통은 설정된 제공자를 이용합니다.
보조 AI는 설정된 API 서버의 Ollama를 사용하며 현재 Supabase 검증 서버에서는 비활성화되어 있습니다.
첫 실행에서 선택적 위치 이용에 동의하고 Android 대략적 위치 권한을 허용하면, 출발지 검색 후보를 가까운 순으로 자동 정렬합니다. 동의 여부만 기기에 저장하며 내 여행에서 변경할 수 있습니다. 현재 위치는 단말기 메모리에서만 사용합니다. 검색 후보의 거리·정렬만 계산하며 현재 위치를 서버·카카오·분석 도구에 전송하거나 계정·파일·백업에 저장하지 않습니다. 검색 화면을 벗어나거나 앱이 백그라운드로 가면 사용을 종료합니다. 거부해도 일반 검색을 이용할 수 있습니다. 연락처·사진첩·백그라운드 위치 권한은 요청하지 않습니다.
사용자가 직접 검색하고 선택한 출발 장소의 좌표는 단말기에서 읽은 현재 위치와 별개이며, 기존 추천·지도 요청 및 사용자가 동의한 여행 저장에 사용됩니다.
지도·이미지·소셜 로그인 및 Cloudflare 중계 접속에서는 제공자가 IP 등 통신 정보를 처리할 수 있습니다.
수탁자/제3자 제공/국외 이전의 구분과 적법 근거, 국가·항목·시점·방식·기간은 실제 배포 계약 기준으로 확정해야 합니다.
만 14세 미만 이용 정책, 법정 보관 예외, 백업 파기 주기, 침해 대응 책임자와 절차도 미확정입니다.

개인정보처리방침 문의 이메일에 개인 Gmail을 사용할 수 있으나, 주소를 실제로 소유·관리하고 요청에 응답해야 합니다.
팀명은 표시용 브랜드로 사용할 수 있지만 실제 책임 운영 주체를 오해하게 표시하면 안 됩니다.
`src/domain/privacyNotice.ts`에 확정한 운영자·문의 주소가 있으며 `PRIVACY_OPERATOR_NAME` 환경변수는 운영 서버의 명시적 재설정용입니다.
