# 와보랑께 스토어 등록 문안

## 앱 이름

와보랑께 - 전남 뚜벅이 여행

## 짧은 설명

전남 관광정보를 식사 시간까지 맞춘 대중교통·도보 코스로 추천해요.

## 자세한 설명

차 없이 전남을 여행할 때, 장소보다 어려운 것은 순서입니다. 와보랑께는 한국관광공사 관광정보의 실제 장소·주소·좌표를 바탕으로 관광지, 음식점, 카페와 시장을 하나의 시간표로 연결합니다.

- 지역, 시작 시간, 여행 길이, 식사 일정, 관심사, 걷기 강도를 직접 선택
- 필요할 때만 자연어 AI로 조건 자동 채우기
- 실제 TourAPI 장소 후보 안에서만 AI 일정 구성
- 음식점 연속 배치, 점심·저녁 시간, 장소 중복, 총 소요시간을 서버가 재검증
- 대중교통 접근성, 도보 부담, 주변 관광 연계성을 반영한 뚜벅이 적합도
- 실제 좌표 지도와 방문 순서, 추천 근거 제공
- 공영 물품보관함은 실제 공공데이터가 있는 코스에서만 표시

코스의 거리와 이동시간은 좌표 기반 추정값입니다. 실제 도로, 대중교통 운행, 운영시간과 요금은 방문 전에 지도·운영기관 정보를 확인해 주세요.

## 카테고리·검색어 제안

- 카테고리: 여행 및 지역정보
- 검색어: 전남여행, 뚜벅이여행, 관광코스, 순천여행, 여수여행, 목포여행

1. 조건을 직접 고르는 안정적인 기본 추천

3. 추천 이유와 뚜벅이 적합도 산정 근거
4. 실제 좌표 기반 코스 지도와 방문 순서
