# 심사위원용 구동 안내

## 서비스 한 줄 소개

와보랑께는 전남의 관광지·음식점·카페·시장을 한국관광공사 관광정보에서 조회하고, 대중교통·도보 여행자가 실제로 따라가기 쉬운 시간표로 재구성하는 앱입니다.

## 권장 시연 시나리오

1. 홈에서 `순천`, `10시 시작`, `6시간`, `시간에 맞춰 자동`, `적게 걷기`, `자연·맛집·카페`를 선택합니다.
2. `이 조건으로 추천받기`를 누릅니다.
3. 추천 목록에서 `AI+검증` 배지와 시작 시간·식사 검증 안내를 확인합니다.
4. 첫 코스를 열어 추천 근거, 점수 가중치, 방문 시간표를 확인합니다.
5. 선택한 역·터미널·숙소가 출발 거점으로 표시되는지 확인합니다.
6. 음식점·카페가 같은 유형으로 연속하지 않고, 점심 음식점이 11:30~13:30에 배치된 뒤 카페가 이어지는지 확인합니다.
6. `동선 보기`에서 실제 TourAPI 좌표를 OpenStreetMap 위에서 확인합니다.
7. 편의 탭에서 실데이터와 시연 정보 배지를 구분해 확인합니다.
8. 홈의 `AI로 조건 자동 채우기`는 선택 기능이며, 문장을 구조화한 뒤 사용자가 수정·확정해야 추천이 시작됩니다.

## 데이터 신뢰 범위

- 장소명·주소·좌표: 한국관광공사 TourAPI
- 코스 순서: Ollama가 실제 후보 ID만 사용해 제안하고 서버 규칙이 재검증
- 거리·이동시간: 좌표 기반 추정값이며 실제 길찾기 결과가 아님
- 보관함·자전거: 화면의 `실데이터` 또는 `시연 정보` 배지로 구분
- 운영시간·요금·혼잡도: 현재 추천 근거로 사용하지 않으며 방문 전 확인 필요
