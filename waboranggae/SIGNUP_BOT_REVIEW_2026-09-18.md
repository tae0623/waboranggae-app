# 회원가입 봇 차단 적용 및 검증

## 적용 범위

- 이메일/비밀번호 **신규 회원가입에만** Cloudflare Turnstile Managed 확인 적용.
- 이메일 인증, 인증 메일 발송, 이메일 비밀번호 복구는 사용자 요청에 따라 도입하지 않음.
- 일반 로그인·카카오/Google 로그인에는 이 확인을 요구하지 않음.
- 기존 가입 요청 제한은 유지. 봇 확인만으로 계정 과다 생성을 완전히 막는 것은 아님.
- Gmail 앱 비밀번호는 사용·업로드하지 않음. 기존 개인 설정 파일은 사용자 입력 보존을 위해 유지.

## 실제 반영

- 서버: 기존 Supabase 프로젝트의 비공개 검증 API에 배포. 공개 서버로 전환하지 않음.
- 웹: https://waboranggae-app.pages.dev 에 직접 배포. 이번 작업에서 GitHub 커밋·푸시는 하지 않음.
- S20+: 기존 데이터 유지 설치. 앱 버전 v1.0.0.
- APK SHA-256: `492e40b4c2feee77906d7ab52a1f24fb4bb8781c984fcb5aa5ccd41eb520dda1`.
- Cloudflare에는 공개 사이트키만, Supabase에는 사이트키·비밀키·강제 검증 설정만 등록.
- 팀 웹 인증과 휴대폰 검증 키의 기존 유효기간은 변경하지 않음.

## 보안 동작

- 서버가 Cloudflare에 확인 토큰을 검증하고 성공 여부·호스트·용도를 검사.
- 토큰 누락·잘못된 토큰·다른 호스트/용도·검증 서비스 장애는 가입 허용으로 처리하지 않음.
- 이메일·닉네임·비밀번호·현재 GPS 좌표는 Cloudflare 서버 검증 요청에 포함하지 않음.
- 단, 확인 화면 접속 시 Cloudflare가 IP·브라우저/기기 접속 정보를 처리할 수 있음을 개인정보 안내에 명시.
- 비밀키·테스트 비밀번호는 앱/웹 번들에 넣지 않으며 관련 개인 설정 파일은 Git 제외.
- 브라우저의 확인 결과 메시지는 고정 호스트와 실제 확인 프레임에서 보낸 것만 수신.
- 공개 확인 페이지는 계정·팀 웹 API에 대한 접속 권한을 제공하지 않음.

## 테스트 계정

- ID: `test`, 닉네임: `테스터`.
- 요청한 비밀번호로 생성하고 실제 서버 로그인 성공 확인.
- 일반 사용자와 동일한 권한. 비밀번호는 DB에 bcrypt 해시로만 저장.
- 로그인 별칭은 관리자 준비 작업에서만 지정 가능. 일반 회원가입에서 별칭을 주입할 수 없음.
- 첫 로그인 때 개인정보 동의가 표시됨. 로그인 시험은 동의를 자동 기록하지 않음.
- 공동 테스트용 계정이므로 실제 개인정보나 개인 여행 정보를 보관하지 말 것.

## 완료된 검증

- 웹/서버 자동 테스트: 64개 파일, 594개 테스트 통과.
- TypeScript: 서버·웹 검사 통과, Pages 빌드/접속 보호 검사 통과.
- Android: 105개 단위 테스트, Debug 빌드 및 lint 완료. 기존 도구 버전 등 경고는 별도 남아 있음.
- S20+ 화면 테스트: 6개 통과. 개인정보 동의와 봇 확인 전에는 가입 버튼이 비활성인 점 포함.
- S20+ **실제** Turnstile WebView → 서버 검증 → 일회용 계정 가입 → 계정 조회 → 해당 임시 계정 삭제까지 통과.
- 위 실기기 검증에서 CAPTCHA를 대신 클릭하거나 해제하지 않음. 위젯이 자동으로 검증한 결과를 사용.
- PC 브라우저에서도 실제 확인 화면의 성공 표시 확인.
- 실제 웹 접속 보호, API 봇 설정, test 로그인·본인 정보 조회·해당 검증 세션 로그아웃 확인.
- 실제 서버에서 봇 토큰 없는 가입 요청이 HTTP 400/SIGNUP_BOT_CHECK로 거절됨을 확인.
- 알려진 로컬 비밀값 기준 Git 대상 텍스트 파일 457개 검사: 발견 0건. 전체 Git 이력/모든 유형의 비밀 탐지를 보장하지 않음.
- 이번 봇 기능 시험에서 카카오 API 호출 0회, 메일 발송 0회.

## 남은 출시 절차

이 문서는 원스토어 제출 완료 또는 무결점 보안 인증을 뜻하지 않는다. 아직 서버는 비공개 검증 모드다. 공개 서비스 운영 전환, 출시용 카카오 Android 패키지/키 해시 등록 확인, 최종 개인정보 처리 현황·스토어 제출 자료 확인은 별도 완료해야 한다. 이메일 미인증 계정의 이메일 소유권이나 이메일을 통한 계정 복구는 이번 버전에서 보장하지 않는다.
