# ver4 새 디자인 통합 검토 기록

기준: origin/ver4, 983c023 (팀원의 waboranggae 디렉터리).
수정 위치: github-upload/waboranggae-app-ver4-review/waboranggae.
기존 ver3 로컬 작업은 그대로 보존했고 이 검토 내용을 원격에 push하지 않았습니다.

## 반영

- 팀원의 새 웹 디자인을 Android/iOS Expo 앱의 공통 UI로 연결. 기존 독립 Expo 화면 대신 같은 web/src/App.tsx 사용.
- 웹 의존성을 pnpm workspace에 포함, 웹 타입 검사/빌드 추가.
- 새 디자인의 고정 지도 그림을 실제 카카오 지도·구간 조회·외부 길찾기 링크로 연결.
- 실제 API 코스의 출발 좌표/관광지 이미지/경로 정보를 UI 변환에서 보존.
- 현재 날씨를 시간별 임의 문구 대신 기상청 초단기 실황으로 연결. 조회 실패·출처·관측 시각 표시.
- 카카오/구글 OAuth 연결 코드와 설정 상태 안내 추가. 미설정 소셜 버튼을 임의로 제거하지 않음.
- 계정 삭제 확인 UI, 웹 개인정보 안내와 외부 계정 삭제 경로 추가.
- 운영 빌드의 임시 API 주소/개발용 암호 혼입 방지, 비밀 파일 Git/EAS 제외.
- 계정 데이터 비동기 요청이 로그아웃 후 화면을 다시 덮어쓰지 않도록 보호.
- 팀 개발 서버/DB 분리와 카카오 무료 쿼터 보호를 ver3 로컬 작업에서 병합.

## 확인한 결과

- 초기 팀 코드: 자동 테스트 64개 통과.
- 최종 자동 테스트 17개 파일·94개 테스트 통과, root 및 web TypeScript 검사 통과.
- 실제 TourAPI 코스 5개 생성: 순천 터미널 출발, 각 6시간, 코스 제목 중복 없음.
- 관광지 이미지 HTTP 200. 카카오 실제 구간 경로 응답. 해당 테스트 중 TMAP 호출 0회.
- Android Expo + DOM 번들 로컬 export 성공. UI 자산이 앱 번들에 포함되는 구조 확인.
- iOS Expo + DOM 번들 로컬 export 성공(실기 실행/서명 빌드 아님).
- 브라우저에서 두 번째 코스를 선택해 동선에 반영되는 것, 터미널 마커, 기상청 현재 날씨 표시 확인.
- 로컬 HTTP 카카오 SDK의 추가 CDN 스크립트 차단을 개발 환경에 한정해 수정. 운영 HTTPS 정책 유지.
- 지도 팝업의 상대 이미지 경로를 수정했고 실제 이미지 로딩 확인. 작은 지도 밖으로 사진이 잘리는 팝업도 지도 내부 패널로 조정.
- 기상청 실응답 성공: 2026-09-15 01:00 KST, 순천 18.8°C / 강수 없음 / 풍속 1.1m/s.
- 팀 DB에 OAuthIdentity 테이블을 추가하는 migration deploy 성공. 기존 데이터 삭제 없음.
- 임시 테스트 계정의 삭제 후 JWT가 인증 단계를 통과하는 문제를 발견해, 계정 존재와 토큰 버전을 DB에서 확인하도록 수정.
- 수정 후 임시 계정으로 가입 → 북마크 → 프로필 민감값 제외 → 계정 삭제 → 기존 토큰 401 차단 실검증 통과. 이 검사에서 만든 계정만 삭제했습니다.

## 완료라고 표시하지 않은 항목

- 휴대폰/에뮬레이터 실행, 서명된 APK/AAB, Google Play 제출·심사.
- 카카오·구글 실계정 로그인: 콘솔 설정 및 실제 로그인 동의 필요.
- Apple 로그인은 사용자 요청으로 웹/앱 공통 UI 및 서버 제공자 목록에서 제거.
- OAuth 상태 저장은 단일 개발 서버 메모리 방식. 여러 API 인스턴스로 운영할 경우 공유 상태 저장소 적용 필요.
- 북마크는 현재 기존 방식인 코스 식별자/제목 위주 저장. 이전 세션의 전체 코스 재열기는 별도 보완 필요.
- 편집 코스의 이동 시간/경로 재계산, 실제 배차 및 장거리/도서 지역의 종합 이동 검증 추가 필요.
- 운영자 연락처·개인정보 처리방침 최종 확정, 영구 HTTPS 배포 주소.

설정 및 실행 안내는 FREE_API_SETUP.md를 참고하세요.
