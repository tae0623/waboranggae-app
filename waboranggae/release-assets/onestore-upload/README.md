## 업로드 방법

1. ZIP을 압축 해제합니다.
2. 판매정보의 ‘그래픽 이미지’에 01-graphic-1024x578.png를 선택합니다.
3. ‘대표 아이콘’에 02-icon-512x512.png를 선택합니다.
4. ‘스크린샷’에는 screenshots 폴더의 4장을 위 순서대로 넣습니다.
5. 판매자 연락처 등 나머지 정보를 확정한 후 저장합니다. 저장과 최종 심사 요청은 별도입니다.

## 규격 검증

- 스크린샷은 필수 2~8장 중 4장, 권장 비율 9:16을 맞췄습니다.
- 가로·세로 모두 최대 1300px 이하이며, 모든 PNG는 파일당 1,000,000 bytes 미만입니다.
- 그래픽과 아이콘도 보수적으로 파일당 1MB 미만으로 준비했습니다. 이 두 항목의 별도 최대 용량은 현재 입력 화면에 표시되지 않았습니다.
- PNG 실제 형식, 해상도, 투명 채널 없음, 파일 용량을 검사했습니다. GPS/EXIF 개인정보를 포함하지 않습니다.
- 그래픽의 주요 내용은 하단 165px 밖에 배치했고, 배경을 완전한 흰색으로 만들지 않았습니다.
- 실제 제출 화면에 더 엄격한 안내가 나타나면 그 안내를 우선합니다. 규격 충족이 심사 승인을 보장하지는 않습니다.

## 화면 출처 및 확인 범위

- S20+에서 현재 Android 코드의 홈과 여행 설정 화면을 새로 촬영했습니다. 기존 계정·GPS·개인 출발지는 사용하지 않았습니다.
- 홈은 실제 공개 여행 소식을 사용하며, 일정 화면에는 예시 선택값 ‘순천 / 2026-09-25’를 넣었습니다. 가짜 관광지나 임의로 만든 추천 결과를 합성하지 않았습니다.
- 실제 화면의 비율·문구·버튼을 유지하고, 외곽에 동일한 배경과 기능 소개 제목만 배치했습니다.
- 이번 촬영은 스토어 소개 화면 준비입니다. 출시 서명 APK 전체 흐름이나 실제 소셜 로그인 검증 완료를 뜻하지 않습니다.
- 지도·발자국 원본 디자인과 팀이 사용권을 확인한 앱 배경을 유지했습니다. 데이터·사진 권리는 원제공자에게 있으며 앱 내 출처 안내를 별도로 유지해야 합니다.
- 홈의 산 배경은 기존 앱 디자인용 이미지입니다. 전남의 특정 산을 촬영한 사진이라고 소개하지 마세요.
