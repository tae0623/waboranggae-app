# 여러 날 추천·지도 조작 개선 (2026-09-17)

## 반영 범위

- Android 설치 아이콘과 앱 내 브랜드, 웹 브랜드에서 사람 실루엣을 발자국으로 교체했습니다. 실제 전남·광주 육지 윤곽과 기존 로딩 발자국 애니메이션은 유지했습니다.
- 출발지 설명 문구를 삭제하고 검색창을 `출발지 검색`으로 통일했습니다.
- 출발지·동선 지도는 화면에서는 미리보기로, 터치하면 앱/웹 안의 전용 확대 화면으로 표시합니다. 일반 스크롤과 지도 드래그의 충돌을 줄였습니다.
- Android 동선의 지도는 스크롤 밖으로 나가도 다시 생성되지 않습니다. 확대 지도에서 이동한 카메라 위치는 닫았다 다시 열어도 복원합니다.
- 웹은 지도 iframe을 유지하며 확대합니다. 크기 변경 시 전체 경로로 다시 맞추던 동작을 현재 중심을 유지하도록 변경했습니다. 출발지 확대 지도에서 선택한 장소의 확인창이 가려지지 않게 보완했습니다.
- 도시 밖 출발은 `출`, 현지 도착지는 `1`로 표시합니다. 이후 번호는 이동 구간이 아닌 방문 장소에 붙입니다. 동선의 `지도에서 보기` 버튼은 제거했습니다.

## 여러 날 추천 방식

한 번 추천을 누르면 최대 7일까지 날짜별 요청을 순서대로 처리하고, 전체 결과를 함께 보여 줍니다. 여러 날은 날짜당 한 코스를 구성하며, 하루 여행은 기존처럼 대안 코스를 표시합니다.

다음 날은 첫날 확인된 현지 출발 거점을 사용합니다. 전날 마지막 장소를 출발지로 이어 붙이지 않습니다. 방문 장소는 앞선 날짜에 배정된 ID·정규화한 이름과 비교해 후보에서 제외하며, 같은 장소의 TourAPI/카카오 중복 표기도 가까운 좌표와 이름으로 보완합니다. 후보 검색과 주변 후보 확장 양쪽에 적용됩니다.

일부 날짜에 적합한 새 코스가 없으면 다른 날의 성공 결과는 유지하고 해당 날짜를 별도로 표시합니다. 중복 장소를 재사용해 성공으로 꾸미지 않습니다. 작은 지역의 모든 날짜에 충분한 코스가 나온다는 보장은 없습니다.

## 설정 시간보다 짧은 코스

이전 코스 우선 모드는 종료 시각을 주로 상한으로 사용하고, 3곳 이상인 후보의 장소 수 우선순위가 같아 짧은 코스가 선택될 수 있었습니다.

종료 시각을 선택한 경우 기존에 계산된 유효 후보 중 현지 시간을 더 알차게 쓰는 후보를 우선하도록 보완했습니다. 최종 결과에서는 제약 통과와 실제 카카오 경로 여부를 우선 유지합니다. 동선에서 남는 시간은 여유 시간으로 표시합니다.

이번 수정은 기존 후보의 순위 개선입니다. 검색 호출을 무제한 늘리거나, 체류시간을 부풀리거나, 긴 우회·중복 식당으로 시간을 채우는 방식은 적용하지 않았습니다. 후보가 실제로 부족한 경우 후속 개선으로 선택형 추가 방문지·주변 소지역 확장을 검토할 수 있습니다.
