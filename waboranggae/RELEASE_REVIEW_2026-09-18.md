# 뚜버기 날짜별 일정 수정 및 출시 전 검증 (2026-09-18)

## 결론

요청한 화면·날짜별 시간·다일 상세 타임라인 변경은 Android와 웹에 반영했다. **현재는 비공개 검증판이며 스토어 제출 완료 상태가 아니다.** 기능 테스트 통과와 운영/법률/스토어 심사 완료를 구분한다.

## 반영 내용

1. 출발지 제목 아래 간격을 다른 단계와 맞추고 검색창을 `출발지를 검색하세요`로 변경.
2. 당일/여러 날 스위치와 별도 종료 날짜 선택을 제거. 달력에서 시작·마지막 날짜를 선택하며 같은 날짜는 당일치기, 최대 7일. 지난 날짜 금지, 월 경계 선택, 큰 글자에서 7열 배치 검사.
3. 사용자 후속 선택에 따라 **날짜마다 시작 시각과 선택적 종료 시각을 직접 설정**. 첫날 시작과 마지막 날 종료를 모든 날짜에 복제하지 않음. 중간 날짜 기본 시작은 09:00이며 화면에서 수정 가능. 종료를 설정하지 않은 날은 기존 코스 중심 추천을 적용하고 밤새 일정을 연결하지 않음.
4. 날짜별 요청 직전에 해당 날짜의 시간·식사 조건을 검증. 식사 버튼은 전체 날짜에서 가능한 종류를 표시하고, 실제 요청에서는 그날 시간에 가능한 식사만 포함. 클라이언트의 전체 `daySchedules`는 API에 전송하지 않음.
5. 상세 타임라인에서 DAY 1부터 마지막 날까지 연속 표시. 실패한 날짜는 숨기지 않고 오류 표시. 이후 날짜의 출발은 현지 거점이며 전날 마지막 관광지로 묶지 않음. 이전 방문 장소 제외 유지.
6. 추천 점수와 뚜벅이 적합도를 각각 이름+점수로 표시. 다일 화면 하단과 분석 탭에는 어떤 날짜의 점수인지 표시.
7. 내 여행의 최근 여행 조건/검색 이력 화면·자동 조회·네이티브 저장/복원용 미사용 코드를 제거. **기존 사용자 DB 기록을 일괄 삭제하지 않음.** 이전 버전 데이터는 계정 삭제 대상에 계속 포함.
8. 닉네임/닉네임 수정으로 통일. 웹에도 프로필 수정 UI 연결. 여러 날 중 저장되는 코스는 선택 날짜 기준임을 팝업에 명시.
9. 웹 API 타입 중복 정의를 공유 타입으로 통합하여 앱/웹 조건의 구조 불일치를 줄임. 지도 터치를 가로채지 않고 자식 지도 제스처를 관찰하는 컨테이너로 교체하고, 달력·여행지 창은 실제 앱 창 크기를 기준으로 계산. 미사용 색상 리소스 제거.

## 출시 전에 반드시 남은 작업

- **배포용 앱이 아직 아님**: Gradle에 release 차단이 남아 있고 버전은 `0.1.0-pilot`, 디버그 서명, S20+ 중심 arm64 구성이다. 운영 서명키의 소유·안전한 보관, 최종 앱 ID/버전, 스토어 제출 APK를 별도로 준비해야 한다. 임시 접속키를 제거한 release에서 재검증해야 한다.
- **공개 운영 방식 승인·검증**: API는 `EDGE_VALIDATION_MODE=true`, 팀 웹은 접속 인증이 있는 개발 환경이다. 일반 사용자용 인증/남용 방어·최종 무료 쿼터·장애 시 동작을 확정한 후 공개 전환해야 한다. 이번 작업은 인증 해제·요금제 변경·호출량 초기화를 하지 않았다.
- **로그인 실계정 최종 확인**: 카카오·구글 계정 각각으로 설치/재실행/취소/로그아웃/철회·삭제 동작을 사용자가 확인해야 한다. 테스트 계정 허용 목록, 운영 리디렉션 주소, 출시 서명 키 해시도 운영 빌드 기준 확인 대상이다.
- **공개 안내와 삭제 경로**: 개인정보·출처·계정삭제 URL은 비로그인 200이며, Supabase 환경에서 의도적으로 읽기 가능한 텍스트를 반환한다. 현재 공개 삭제 안내는 앱에서 삭제하거나 문의 이메일로 요청하는 방식이다. 브라우저 자체 삭제 화면은 미완성이다. 처리방침 내용·외부 처리/보관·출처 표시·실제 지원 절차 및 원스토어 제출 항목을 운영자가 최종 검토해야 한다. 법률 적합성을 보증한 검사가 아니다.
- **운영 복구/부하**: 장시간·동시 사용자 부하, 실제 통신 중단/재접속, 데이터 백업 복원, 모니터링·알림, 모든 Android 기종/OS와 장기간 무료 한도 검증은 완료되지 않았다.
- **추천 결과의 한계**: 후보가 적거나 이동·식사·영업시간 근거가 부족한 날짜는 더 짧은 코스 또는 실패 안내가 나올 수 있다. 식당 영업 여부와 실시간 버스 도착을 확정 정보처럼 보장하지 않는다. 날짜별 코스 저장은 지원하지만 여러 날 여행 전체를 하나의 북마크로 복원하는 기능은 별도다.

## 변경하지 않은 항목

- 기존 Expo 프로젝트 삭제, 사용자 데이터 삭제, 원스토어 제출, 공개 서비스 전환, 유료 서비스 전환은 하지 않음.
- 외부 API 서버 추천 알고리즘은 이번 날짜별 UI 작업에서 변경하지 않음. 클라이언트가 날짜별 검증된 단일 일정을 기존 API로 보냄.
- 관련 없는 기존 `FREE_FIXED_WEB_SETUP.md`, `deployment/pages/VALIDATION.md` 및 Cloudflare 관리 스크립트 변경은 이 작업의 커밋에서 제외.
- 갱신한 S20+ 키 만료: **2026-09-19 01:21 KST**. 만료 이후에는 비공개 앱의 API 접속이 막히며, 이는 출시 운영 방식으로 사용하면 안 됨.
