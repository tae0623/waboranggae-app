# 웹 → 네이티브 복원 범위

기준: 현재 `web/src/App.tsx`. Kotlin / Jetpack Compose 구현이며 기존 웹·Expo 프로젝트는 보존합니다.

| 영역 | 네이티브 상태 |
| --- | --- |
| 브랜드·시작 | 걷는 사람 + 기존 전남 지도·발자국. 시작 그림은 SVG 최종 모습, 긴 선 그리기 애니메이션은 미이식 |
| 설치 아이콘 | Google Noto Emoji 걷는 사람 (Apache 2.0), 원형/사각형 런처 대응. Samsung 시스템 그림 추출본 대체 |
| 홈 | 사진 배경·전남 여행 소식·상세 정보·5단계 진입·원본 톤 유지 |
| 로그인 | 이메일 로그인/가입, 카카오/구글 외부 브라우저 인증, 게스트 진입. Apple 없음 |
| 개인정보 | 가입/소셜 동의, 개별 저장 동의, 안내·출처·공개 문의 이메일 |
| 내 여행 | 이름 수정, 코스 원본 저장/열기/제거, 이력 조회/조건 복원/개별·전체 삭제, 로그아웃·계정 삭제 |
| 조건 선택 | 출발지 실제 검색, 지역, 당일/여러 날(최대72h), 숙소 실제 검색, 동행, 식사 직접 선택, 교통 |
| 코스 상세 | 시간표, 점수 세부값, 추천 이유, 요청 시 AI 추가 설명, 기상청 현재 관측 |

| 지도 | 상세에서 동선 확인, 코스 ID 전환, 출발지·관광지 핀·사진·외부 카카오 링크, 선택 해제 |
| 디자인 | Pretendard·흑백/회색/보라/청록, 둥근 카드·원본 선형 메뉴 아이콘 |
| 알림 | 기존 웹도 발송 기능이 없었던 안내 영역. 실제 푸시·예약 알림 미구현 |
| 자연어 입력 | 현재 웹도 UI 선택이 중심. 네이티브에는 자연어 조건 입력창 없음, 추가 추천 설명은 연결 |

## 남아 있는 차이

- 웹의 CSS와 Compose는 별도 구현이므로 픽셀 단위 동일 화면이나 이후 웹 변경의 자동 반영은 아닙니다.
- 관광사진의 잘림/임의 변형을 줄이기 위해 네이티브는 원본 비율 Fit 표시를 사용합니다.
- 이미지 없음은 빈 상태로 표시합니다. 웹 상세의 무관한 고정 Unsplash 사진과 대표 사진 대체값을 제거했습니다.
- 저장한 과거 코스는 당시 원본입니다. 현재 영업·운행 정보가 아니므로 다시 추천 권고. 저장 코스에서 조건이 없으면 AI 재설명·편집을 비활성화합니다.
- “이 지역으로 코스 만들기”는 지역·취향을 채울 뿐 해당 관광지가 반드시 포함된다고 보장하지 않습니다.
- 여러 날 입력/API 연결을 당일 수준의 현장 검증·숙박예약 완료로 표시하지 않습니다.

## 저작권 확인

- 지도·발자국/선형 아이콘: 기존 웹 소스 이전. 팀의 원저작물/사용 허락 확인이 아직 필요합니다.
- 걷는 사람: Noto SVG의 원 라이선스·NOTICE·Apache 전체 문구를 앱 assets에 동봉.
- 글꼴: Pretendard v1.3.9, SIL OFL1.1 원문 동봉.
- 관광사진: 한국관광공사/포토코리아. 제공되는 촬영자 정보는 보존, 유형 누락은 미확인으로 처리.
  공개 출시 전 사진별 제1/제3유형, 저작자·원 제공처 조건을 확인해야 합니다.
