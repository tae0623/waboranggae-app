# 뚜버기 수정 버전 테스트 결과

검사일: 2026-09-18 (한국 시간)

## 현재 상태

- 사용자의 최신 요청에 따라 출시 준비·공개 전환·원스토어 제출은 보류했다.
- 기존 테스트 패키지 `kr.co.waboranggae.nativepilot`을 S20+에 덮어 설치했다. 계정·앱 데이터를 초기화하지 않았다.
- Supabase는 기존 비공개 검증 모드로 코드만 재배포했다. 비밀값 업로드, 호출 한도 변경, 공개 전환은 하지 않았다. 배포 revision: `ce5e1b2c5cc2a7a5`.
- 웹 소스·빌드는 수정했고 로컬 모의 API로 화면을 검증했다. 이번 변경을 GitHub나 Cloudflare Pages에 업로드하지는 않았다.
- 이미 승인받아 생성한 정식 서명키는 `.release-private/`에 보관 중이다. 정식 패키지·키 해시 등록 및 정식 APK 제작은 진행하지 않는다. 이 폴더와 `android-native/release.properties`는 Git 제외 대상이다.

## 반영한 내용

1. 여러 날 추천을 한 카드로 묶고, 날짜별 장소와 추천 점수·뚜벅이 적합도를 구분했다. 상세 상단은 전체 여행 요약, 점수 분석·타임라인은 날짜별 표시다.
2. 저장 성공 후 목록 재조회 실패가 동선 화면 이동까지 막지 않도록 분리했다. 저장 자체가 실패하면 재시도 또는 저장 없이 여행하기를 선택할 수 있다.
3. 동선의 승차·하차·이동을 카드와 화살표로 나누고, 연속 도보 안내를 접어 볼 수 있게 했다. 도보 시간은 총 이동 시간에서 제외하지 않는다.
4. 검색 한도/연결 오류 팝업, 닉네임 수정 완료 팝업을 추가했다. 검색은 지연 입력 처리와 메모리 캐시를 사용한다.
5. 내 여행은 로그인 정보 → 저장한 코스 → 로그아웃 → 계정 탈퇴 순서다. 우측 설정에서 닉네임·위치 이용·앱 정보·법적 안내를 확인한다.
6. 닉네임 변경은 로그인 사용자 ID에 연결된 DB 프로필을 수정하는 기존 API를 사용하며, 서버에서 공백도 정리한다. 별도 기기 전용 이름으로 저장하지 않는다.
7. 홈 상단 로고·브랜드 문구와 알림 제어를 제거했다. 필수 개인정보·데이터·오픈소스 안내는 설정에 유지한다.
8. 비밀번호 대문자 필수 조건만 제거했다. 길이·숫자·소문자·특수문자와 bcrypt 입력 크기 제한은 유지한다.
9. 편집 화면을 드래그 핸들·X 삭제·장소 추가 시트로 정리했다. 공개 장소 좌표의 직선 우회거리로 추천 후보를 정렬하고 가장 가까운 삽입 위치에 추가한다. 실제 이동 시간은 편집 저장 요청에서 기존 서버 로직으로 다시 검증한다.
10. 여러 날 추천에서 다른 후보 코스에 있었던 장소도 편집 후보로 보관한다. 다른 날 선택된 장소 ID는 추가 후보에서 제외한다. 추가 후보 조회용 카카오 요청은 새로 만들지 않는다.

## 아직 적용하지 않은 기능과 한계

- 실시간 버스 도착: TAGO 버스도착정보의 도시 목록을 1회 시험했으나 HTTP 403으로 접근하지 못했다. 신청 여부/권한·서비스 상태 확인이 필요하다. 기존 버스정류소·노선 조회 승인과 별도 서비스이며, 도입 시 정류장·노선 ID의 정확한 연결도 필요하다. 이름만 보고 도착 정보를 연결하지 않았다. [공식 서비스](https://www.data.go.kr/data/15098530/openapi.do)
- GPS 실시간 내비게이션: 적용하지 않았다. GPS는 동의한 경우 단말 내부 검색 정렬에만 사용한다. 검색·선택한 장소 중심 지도 원칙을 유지한다. 도보 안내를 전부 없애면 길 안내가 사라지므로 접기 형태로 유지했다.
- 장소 추가의 가까운 순서는 직선거리 기반 편집 보조다. 도로·산·강을 반영한 실제 이동 시간 보장은 아니다. 후보가 적으면 목록도 적을 수 있다.
- 여러 날 저장은 날짜별 코스를 각각 저장한다. 저장 목록에서 다시 열 때 전체 여러 날 묶음을 복원하는 별도 저장 형식은 아직 없다.
- 저장 API의 기존 스냅샷 크기 제한은 유지한다. 후속 모바일 수정에서 큰 지도 경로 좌표를 저장용으로 간소화하고 HTTP 413 및 잘못된 로그인 팝업 문제를 보완했다. 상세 결과: `MOBILE_SAVE_FIX_2026-09-18.md`.
- APK는 만료형 접속 키가 들어 있는 비공개 테스트용이다. 스토어에 제출하면 안 된다. 현재 키 만료: 2026-09-19 01:21 KST. 만료 시 갱신 승인과 재설치가 필요하다.
- 보안 검사는 현재 코드·알려진 비밀값·대표 인증/입력 오류에 대한 검사다. 전체 Git 이력, 모든 의존성 취약점, 전문 침투검사를 완료했다는 의미가 아니다.

## 사용자가 먼저 확인할 순서

1. S20+에서 뚜버기를 열고 2일 이상 날짜를 선택한다.
2. 결과가 한 카드에 표시되고 날짜별 점수가 나오는지 확인한다.
3. 날짜별 편집에서 핸들을 끌고 X로 지운 뒤 장소 추가·저장을 확인한다.
4. 로그인한 상태에서 코스 저장 → 여행 동선 이동을 확인한다.
5. 내 여행의 설정·닉네임·로그아웃 배치와 전체 화면 디자인을 확인한다.

사용자 확인 후에만 정식 패키지 등록, 키 백업, 공개 운영 전환, 스토어 제출 준비를 재개한다.
