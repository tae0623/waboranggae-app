## 여러 날 추천의 범위

- 서버에는 날짜별 단일 일정을 요청한다. 날짜가 바뀌면 식사와 시간 조건도 그 날짜 기준으로 다시 계산한다.
- 첫날 추천 응답의 현지 출발지를 이후 날짜의 공통 출발지로 사용한다. 전날 선택 코스의 종착지에는 영향을 받지 않는다.
- 같은 지역·같은 취향에서 날짜별 장소가 겹칠 수 있다. 숙박 연계와 여러 날 전체의 방문 중복 제거는 이번 기능에 포함하지 않았다.
- 최대 7일이며 예보 제공 범위를 벗어난 날은 실제 예보가 있는 것처럼 표시하지 않는다.
- 서로 다른 날의 코스 ID에 날짜를 포함하여 저장·선택 충돌을 방지한다.

## 지도·길찾기의 범위

- 제공받은 도보·대중교통 경로 좌표와 단계별 노선/정류장 정보를 사용한다. 경로가 누락된 구간은 추정 표시를 유지한다.
- 떨어진 경로 조각 사이에 임의의 선을 만들어 ‘실제 도로 경로’로 표시하지 않는다.
- 네이버/카카오 소비자 앱과 같은 실시간 버스 도착·혼잡도·음성 안내는 구현하지 않았다. 이번 REST API 응답이 제공하지 않는 값은 만들지 않는다.
- 출발지 지도 터치 기능의 장소 정보는 명칭·주소 및 출발지 지정이다. 리뷰·평점·영업 여부까지 제공하는 장소 상세 서비스는 아니다.
- 카카오 문서: https://developers.kakao.com/docs/ko/kakaomap/rest-api

## 개인정보·보안

- 현재 위치/GPS는 서버와 카카오에 보내지 않는다. 명시적으로 지도에서 선택한 공개 좌표만 주소 확인에 사용한다.
- 지도 메시지는 출처와 iframe/window 일치 여부를 확인한다. 잘못된 출처의 메시지는 무시한다.
- 지도 주소 확인 API는 엄격한 입력 스키마, 범위 검사, 호출 제한, 기존 비공개 접속 인증을 적용한다. GPS 출처로 위장한 요청은 거절한다.
- 기존 비공개 서버 인증, 키 만료, 백업 금지·평문 통신 금지는 유지. 비밀키 갱신·요금제 변경·개인정보 동의 변경은 하지 않았다.
- 출처 통합은 권리 포기가 아니다. 사진 개별 이용 조건·스토어 제출 관련 법적 검토까지 완료했다는 의미는 아니다.
