# ver5 소스 동기화 및 이메일 도메인 차단

## 변경 범위

- 원격 기준 `7d07206`: 로컬 기준과 동일하며 이 작업 직전 확인에서 원격에만 있는 커밋 없음.
- 기존 로컬 후속 수정 포함: Android/웹 여행 UI·편집·계정 설정, 코스 저장 처리, 봇 확인, 공유 요청 제한, 개인정보·약관 페이지, DB 로그인 별칭 마이그레이션, 배포 보조 도구, 공개 스토어 이미지.
- 신규: 이메일 회원가입 일회용 도메인 차단, CC0 목록 8,896개, 고정 원본 커밋/라이선스, 수동 갱신 도구, 정확한 도메인 예외·추가 차단 설정.
- Android: 해당 오류 코드에서 차단 사유를 안내. 내부 오류 원문은 화면에 표시하지 않음.
- 팀원 문서: 현재 Android·웹 구조, 수정 위치, 실행·테스트·별도 배포 절차를 README와 TEAM_HANDOFF에 정리.
- Git 제외 및 검사: 서명키·APK·AAB·압축 산출물 제외 강화, 로컬 모든 환경 파일의 알려진 비밀값과 Git 인덱스 검사 지원.

## 적용 범위

GitHub 커밋만으로 Supabase API가 갱신되지 않습니다. 일회용 도메인 실제 차단은 API 재배포 후 적용됩니다. Android의 새 안내 문구는 새 APK를 배포해야 적용됩니다. 이번 작업은 운영 서버 배포나 원스토어 후속 업데이트를 포함하지 않습니다.

기존 로그인 및 테스트 별칭은 유지됩니다. 데이터베이스 계정을 삭제하거나 소급 차단하지 않습니다. 목록은 모든 일회용 주소를 잡는 보장이 없고, 이메일 소유권 확인을 대체하지 않습니다.

원스토어 출시 완료는 운영자 확인에 따른 상태입니다. 이 후속 개발 커밋을 스토어에 제출했던 바이너리와 동일한 소스라고 표시하지 않습니다.
