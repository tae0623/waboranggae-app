# 카카오 한도 갱신 후 실제 연동 검증

대상: 고정 비공개 팀 웹 `https://waboranggae-app.pages.dev/` → 기존 Supabase API.
API 최종 빌드: `34cff2e124810083`. 검증 날짜: 2026-09-17 한국 시간.

## 확인하고 수정한 오류

1. **같은 관광지 중복 방문**: TourAPI의 `나주 금성관`과 카카오의 `금성관`을 서로 다른 장소로 취급했습니다. 도시 접두어를 정규화하되 좌표 150m 이내·호환되는 장소 분류를 함께 확인해 합칩니다. 다른 별관/동명 원거리 장소는 유지하고, 우선 데이터의 ID와 사진을 보존합니다.
2. **제목에서 장소명 손상**: `순천시립 그림책 도서관`이 `립 그림책 도서관`으로 잘리던 접두어 제거를 고쳤습니다.
3. **이동 시간의 잘못된 분류**: 실제 카카오 응답에서 총 930초이지만 BUS 상세는 543초뿐인 구간을 발견했습니다. 총시간은 그대로 유지하고, 분 단위 잔여 6분을 `추가 이동·대기 / 세부 구분 미제공`으로 표시합니다. 이를 버스 탑승이나 도보라고 단정하지 않고 환승으로도 세지 않습니다. 도보 점수는 미분류 시간이 0분 걷기라는 뜻으로 유리하게 계산되지 않도록 보수적으로 평가합니다.
4. **지도 관광사진**: HTTP 관광사진도 카드와 같은 인증된 HTTPS 이미지 프록시를 사용하도록 했습니다. 이미지 내부 출처 오버레이는 추가하지 않았으며 기존 출처 안내는 유지합니다.
5. **출발지 도시 인식**: 주소의 광역 행정구역 접두어보다 실제 전남 시·군을 우선 확인합니다.

시간 응답 호환성: 기존 클라이언트를 위해 `transitMinutes`에는 미분류 부분이 포함됩니다. 새 `unclassifiedMinutes`는 그 부분집합이며, 새 웹/Android 화면은 이를 뺀 대중교통 시간과 미분류 시간을 별도로 표시합니다. 총 이동 시간에 중복 가산하지 않습니다.
카카오 응답 필드 기준: [공식 REST API 문서](https://developers.kakao.com/docs/ko/kakaomap/rest-api).

## 실제 API 검증

GPS나 실계정 없이 공개 터미널을 출발지로 선택했습니다. 실제 공급자 데이터만 사용하고 예시 코스로 대체하지 않았습니다.

| 조건 | 확인 결과 |
| --- | --- |
| 순천 터미널 → 순천 / 자연·역사·식사 자동 | 실제 코스 3개, 카카오 경로, 서로 다른 제목, 중복 장소 없음 |
| 광주 터미널 → 나주 / 역사·식사 자동 | 실제 코스 3개, 금성관 중복 제거, 나주 터미널부터 현지 시간 계산 |
| 광주 터미널 → 담양 / 자연·카페 / 식사 제외 | 실제 코스 3개, 식당 미포함, 담양 터미널부터 현지 시간 계산 |
| 순천 터미널 → 순천 / 오전 8시 / 아침 선택 | 실제 코스 3개, 식사 시간 조건 검증 통과 |

- 카카오 장소 검색, 추천, 전체 코스 경로 갱신, 마지막 장소 제외 후 재계산, 지도 HTML, 관광사진 HTTP 응답을 확인했습니다.
- 최종 빌드의 네 조건 검사 117개 통과. 최종 추천 응답은 순천 6.4초, 나주 4.2초, 담양 3.8초, 아침 조건 5.0초였습니다(일회성 측정, 성능 보장값 아님).
- 오늘 누적 카카오 보호 한도 사용량은 검사 종료 시 292/1,000회였습니다. SDK 호출량은 이 서버의 REST 보호 카운터와 별도입니다.
- 시간 구성 합계와 구간 이동 합계, 실제 장소 출처, 식당·카페 연속 배치 방지, 코스 제목 구분을 검사했습니다.
- 도시 간 이동은 현지 시간에서 제외됩니다. 광주→나주/담양의 도시 간 경로는 공급자가 반환하지 않아 **시간 미확인 + 외부 길찾기**로 남습니다. 임의 시간을 넣지 않았습니다.
- 지도 SDK는 고정 Pages 주소를 Referer로 전달했을 때 JavaScript를 HTTP 200으로 반환했습니다. 이 결과만으로 화면 렌더링을 검증했다고 보지는 않습니다.
- 식당 영업 여부, 카카오 검색 순위의 맛집 인증 여부를 보장하지 않습니다.

## 회귀 및 보안 검사

- JavaScript/TypeScript 테스트 **497개**, 루트·웹 타입 검사 통과.
- Android 컴파일 및 단위 테스트 **80개** 통과. 휴대폰 설치는 하지 않았습니다.
- Pages 빌드·인증 게이트웨이 검사 통과, 알려진 비밀값과 비공개 설정의 Git 노출 검사 0건.
- 비밀값 재전송, 인증 범위 확장, GPS 전송, 유료 설정 변경, 한도 초기화/증가는 하지 않았습니다. 기존 하루 합계 1,000회 보호 한도를 그대로 유지합니다.
- 원시 응답과 검사 스크립트는 로컬 `.runtime/kakao-after-midnight`에만 두며 GitHub에 올리지 않습니다.

## 아직 구분해서 확인할 항목

- 자동화 브라우저는 비공개 Pages 열기를 `ERR_BLOCKED_BY_CLIENT`로 차단했습니다. 따라서 **실제 브라우저의 지도 렌더링·마커 호버·이미지 표시·코스 전환**은 이번 실제 API 검사만으로 완료 처리하지 않습니다. 이전 UI 테스트 데이터 검사와도 구분합니다.
- 실제 사용자 카카오/Google 로그인 완료는 사용자 직접 인증이 필요합니다.
- S20+ 전용 테스트 접속 키는 2026-09-16 23:32 KST에 만료되었습니다. 30일짜리 팀 웹 키와 별개이며 이번 작업에서 임의 연장하지 않았습니다. 휴대폰 재검증에는 전용 키 갱신과 재설치가 필요합니다.
