# 와보랑께 개인정보처리방침

시행일: 2026년 8월 23일

와보랑께는 전라남도 대중교통·도보 여행 코스를 추천하는 서비스입니다. 로그인하지 않고 지역·시간·관심사를 선택하여 기본 추천 기능을 이용할 수 있습니다.

## 1. 처리하는 정보

- 비회원 이용: 사용자가 선택하거나 입력한 여행 지역, 출발지 유형, 시작 시간, 여행 시간, 관심사, 이동 조건
- 서버 운영 과정: 장애 대응과 보안을 위한 최소한의 접속 기록이 서버 운영 환경에서 생성될 수 있음

현재 공개 화면은 로그인·회원가입을 제공하지 않으며 이메일, 기기 위치, 연락처, 사진, 광고 식별자를 수집하지 않습니다. 앱의 API 키는 서버에만 저장되며 모바일 앱에 포함되지 않습니다.

## 2. 이용 목적

입력 정보는 여행 조건 분석, 관광 코스 추천, 추천 이유 제공, 서비스 보안과 장애 대응에 사용합니다.

## 3. 보관 및 삭제

여행 조건은 코스 응답 생성에 사용되며 앱에서 계정 정보로 저장하지 않습니다. 서버 운영 로그가 생성되는 경우 보안·장애 대응에 필요한 최소 기간 뒤 삭제합니다.

## 4. 외부 서비스와 데이터 전송

- 한국관광공사 TourAPI 및 공공데이터 API: 서버가 관광·교통·편의시설 정보를 조회합니다. 사용자 이메일이나 비밀번호를 전송하지 않습니다.
- Ollama: 운영 서버 안의 오픈소스 언어 모델이 여행 문장을 조건으로 변환하고 조회된 코스의 설명을 생성합니다. 외부 상용 LLM API로 전송하지 않습니다.
- OpenStreetMap: 지도 화면에서 지도 타일을 불러올 때 네트워크 주소 등 통상적인 접속 정보가 지도 제공자에게 전달될 수 있습니다.

## 5. 이용자 권리

이용자는 앱을 종료하거나 입력을 변경하여 추천 조건을 관리할 수 있으며, 서버 기록 관련 문의는 아래 운영자 연락처로 요청할 수 있습니다.

## 6. 안전성 확보 조치

API 키의 서버 보관, 비밀번호 단방향 해시, 인증 토큰 검증, 요청 횟수 제한, 입력값 검증, 보안 헤더를 적용합니다. 배포 서버와 앱의 통신은 HTTPS를 사용합니다.

## 7. 문의

- 서비스명: 와보랑께
- 운영자: 와보랑께 개발팀
- 문의 이메일: 프로젝트 배포 전 운영 이메일로 교체 필요

운영 주체, 문의 이메일 또는 처리 내용이 변경되면 이 문서를 갱신하고 앱 스토어 등록정보에 공개 URL을 반영합니다.
